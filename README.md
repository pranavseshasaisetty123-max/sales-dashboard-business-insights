# Sales Dashboard & Business Insights

## Project Overview
Interactive Tableau dashboard built using Superstore sales data to analyze revenue, profit, orders, category performance, and regional performance.

## KPIs
- Total Revenue
- Total Profit
- Total Orders

## Dashboard Features
- Sales Trend Analysis
- Revenue by Product Category
- Profit by Product Category
- Sales by Region
- Profit by Region
- Interactive Dashboard Design

## Key Insights
- Technology generated the highest revenue.
- Technology generated the highest profit.
- West region recorded the highest sales and profit.
- South region recorded the lowest sales.
- Sales showed an overall upward trend.

## Tools Used
- Tableau Public
- CSV Dataset
- Data Visualization
